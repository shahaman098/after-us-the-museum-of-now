# AFTER US

AFTER US is the actual SummerHacks product project.

Pitch:

Photograph one ordinary object that matters to you. AFTER US transforms it into a museum exhibit from the year 2526, building a living public archive of what it meant to be human in 2026.

This directory is intentionally separate from `hackathon-strategy-engine`, which is only the research and strategy repo used earlier.

## Build Goal

Create a public, visually distinctive web app that:

- accepts one real-world object contribution
- visibly transforms it into a future-museum exhibit
- publishes it into a shared museum
- exposes a public `Census of Us` data view
